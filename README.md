# 🧠 NeuroVision-AI: Brain Tumor Classification using Deep Learning

This project presents a deep learning-based system for accurate classification of brain tumors using MRI images. It leverages Convolutional Neural Networks (CNN) and transfer learning techniques to perform multi-class classification, supporting medical diagnosis through AI-driven insights.

---

## 🚀 Overview

Brain tumors are among the most critical neurological disorders, and early detection plays a vital role in effective treatment. This project aims to build an intelligent system that can automatically classify MRI scans into different tumor categories using deep learning models.

---

## 🎯 Objectives

- Develop a robust deep learning model for brain tumor classification  
- Achieve high accuracy in multi-class prediction  
- Automate the detection process using MRI images  
- Provide a foundation for real-world medical AI applications  

---

The model is trained on MRI brain scan images categorized into four classes:

- Glioma Tumor  
- Meningioma Tumor  
- Pituitary Tumor  
- No Tumor
